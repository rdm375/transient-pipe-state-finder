# Continuation candidates

- Steady-state proximity regularization with decreasing weight.
- Pre-evolution mapping z0 = S_tau(z_minus_tau), shortening tau during continuation; requires prehistory boundary conditions.
- Parameterized boundary-history generation from a reference steady state; restricts the reachable family and may reduce dimension.
- Observation bandwidth continuation.

A forward-generated state satisfies the numerical dynamics, but not every physical state is necessarily reachable from a restricted history family. Test identifiability separately from optimizer convergence.
